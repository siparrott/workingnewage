## Part A — What the platform does (every sidebar tool)

A single system that runs an entire photography studio end-to-end: leads → booking →
shoot → delivery → invoicing → marketing.

| Tool | What it does |
|---|---|
| **Dashboard** | At-a-glance overview of the studio: leads, revenue, activity. |
| **New Leads** | Inbox of prospects from website forms, waitlist and manual entry; status tracking (new → contacted → converted) with email alerts. |
| **Online Voucher Sales** | Sells photo-shoot gift vouchers online (Stripe), with discount codes, product/price management, and a live sales list. |
| **Clients** | The CRM record: contact details, lifetime value, invoice history, sessions, emails, and questionnaires per client. |
| **Top Clients** | High-value client view for prioritising relationships. |
| **Lead Sources** | Tracks where leads come from, with conversion analytics per source. |
| **Galleries** | Private, password-protected client galleries for proofing and delivery. |
| **Invoices** | Create, send and track invoices (paid/unpaid/overdue), with PDF export. |
| **Accounting Export** | Exports financials for the bookkeeper/accountant. |
| **Price List Wizard** | AI-assisted price-list builder for packages and products. |
| **Calendar** | Studio calendar with **two-way Google Calendar sync** so availability is always accurate. |
| **Schedulers** | Public booking flow — clients pick real open slots (blocked against Google Calendar) without double-booking. |
| **Cloud Storage / Digital Files** | Stores and delivers final files; "My Archive" for deliverables (S3/Backblaze-backed). |
| **Blog** | Full blog engine: write, schedule, publish, tag; case studies inherit SEO, sitemap and IndexNow automatically. |
| **Email Campaigns** | Newsletter/broadcast email with real open/click analytics and subscriber management + CSV export. |
| **Automations** | Triggered emails (e.g. the €50 newsletter voucher, booking follow-ups) editable without code. |
| **Communications** | Outbound SMS/WhatsApp to clients, logged against the client record. |
| **Inbox** | Unified email inbox; inbound mail auto-links to the matching client. |
| **Questionnaires** | Send pre-shoot questionnaires; responses auto-file to the client and feed case-study production. |
| **Reports** | Revenue, conversion and performance reporting. |
| **Landing Pages** | AI-built, per-campaign landing pages with signed voucher offers and analytics. |
| **Agent V2** | Built-in AI assistant across CRM data (campaigns, clients, vouchers, blog, etc.). |
| **Settings** | Studio templates, Website Wizard/Analyzer, Manual Website Update, Knowledge Base, Agent Console. |

**Cross-cutting strengths:** Stripe payments, server-signed tamper-proof voucher pricing,
product-restricted discount codes, IndexNow + sitemap SEO automation, GA4/Meta conversion
tracking, bilingual (DE/EN) with on-the-fly translation, and an outward integration API
(**ShootCleaner**) for galleries, files, clients, questionnaires and blog.
